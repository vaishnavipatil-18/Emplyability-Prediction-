# Emplyability-Prediction-
Built a hybrid deep learning + gradient boosting pipeline (GloVe embeddings → BiLSTM → XGBoost) to predict student employability from academic features on a 50K-record dataset; engineered leakage-free target-encoded skill features, addressed class imbalance via weighted loss functions, and achieved 0.84 ROC-AUC with tuned classification thresholds.
